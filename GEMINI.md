# GEMINI.md

**All coding, documentation, and testing conventions for this repository live in
[AGENTS.md](AGENTS.md). Read that file before making any edit.**

This file exists only so that Gemini CLI picks up the shared instructions. Conventions are
maintained in exactly one place so that every agent and every human contributor works from
the same rules.

Do not add project conventions here. Add them to [AGENTS.md](AGENTS.md).

## PR descriptions

When creating a pull request, add this footer at the very end of the PR body:

```
Generated by gemini-2.0-flash
```

(Replace with the actual model ID that generated the PR.)
