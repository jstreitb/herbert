# CLAUDE.md

**All coding, documentation, and testing conventions for this repository live in
[AGENTS.md](AGENTS.md). Read that file before making any edit.**

This file exists only so that Claude Code picks up the shared instructions. It is
intentionally a pointer and nothing more — conventions are maintained in exactly one
place so that every agent (Claude, Cursor, Copilot, Gemini, Aider, …) and every human
contributor works from the same rules.

Do not add project conventions here. Add them to [AGENTS.md](AGENTS.md).

Quick orientation before you open it:

- Four components: `/mod` (Java, records gameplay), `/nn` (Python, behavioral cloning),
  `/rl` (Python + Node.js, PPO fine-tuning), `/bot` (Python, **private — never commit**).
- They are bound together by a shared JSONL session schema documented in `mod/README.md`.
- `AGENTS.md` §2 "Hard rules" and §7 "Cross-component invariants" cover things that fail
  *silently* if you get them wrong. Those two sections are the ones worth reading twice.
